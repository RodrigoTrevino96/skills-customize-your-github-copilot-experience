# 📘 Assignment: Algorithms with Lists and Dictionaries

## 🎯 Objective

Practice problem-solving with Python lists and dictionaries by building small algorithms to summarize scores and count word frequency.

## 📝 Tasks

### 🛠️	Analyze Student Scores

#### Description
Write a function that receives a list of integer scores and returns a summary of the class performance.

#### Requirements
Completed program should:

- Implement `analyze_scores(scores)`
- Return a dictionary with keys: `min`, `max`, `average`, and `passed`
- Use a passing score of 60 and count how many students passed
- Print the returned summary for the sample list in starter code


### 🛠️	Count Word Frequency

#### Description
Write a function that receives a sentence and counts how many times each word appears.

#### Requirements
Completed program should:

- Implement `count_words(sentence)`
- Ignore uppercase/lowercase differences (treat "Python" and "python" as the same)
- Return a dictionary where keys are words and values are counts
- Print the 3 most frequent words from the sample sentence in starter code
